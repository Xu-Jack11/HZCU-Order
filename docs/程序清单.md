# 程序清单（HZCU-Order）

> 快速了解项目结构、职责与运行方式。

## 项目概览
- 类型：校园点餐系统（后端 Java + 前端 Next.js + 微信小程序）
- 子模块：
  - backend：Spring Boot 服务，MySQL 持久化
  - web：Next.js 管理端与用户端 Web 应用
  - wxapp：微信小程序端
  - docs：设计与文档

## 运行入口
- 后端：
  - 主类：`backend/src/main/java/com/hzcu/order/HzcuOrderApplication.java`
  - 配置：`backend/src/main/resources/application.yml`
  - 数据源：`jdbc:mysql://127.0.0.1:3306/diancan`（用户：root，密码：123456）
  - 端口：`8080`，上下文：`/api/v1`
- Web 前端：
  - 目录：`web/`
  - 启动：`npm install`，`npm run dev`
  - 开发端口：默认 `3000`
- 微信小程序：
  - 目录：`wxapp/miniprogram/`
  - 入口：`app.ts`，`app.json`

## 关键文件与目录
- 根目录
  - `dc1.sql`：另一套数据库结构样例（库 dc1）
  - `project.config.json`：项目配置
  - `README.md`：项目说明
- backend/
  - `pom.xml`：Maven 配置
  - `src/main/resources/application.yml`：Spring Boot 配置（数据源、Hikari、JDBC）
  - `src/main/java/com/hzcu/order/repository/ShopJdbcRepository.java`：商家仓储（已切换表 `canteenshops`）
  - `src/main/java/com/hzcu/order/controller/CanteenController.java`：食堂相关接口
  - `src/main/java/com/hzcu/order/service/CanteenService.java`：食堂业务逻辑
  - `src/main/java/com/hzcu/order/data/DataStore.java`：内存数据种子（演示用）
- web/
  - `package.json`：前端依赖与脚本
  - `app/`：Next.js App 路由（dashboard、admin、login 等）
  - `components/`：UI 组件（`OrderCard.tsx`、`Sidebar.tsx` 等）
  - `lib/api.ts`：前端 API 调用封装（含 `/shops` 兼容逻辑）
  - `public/`：静态资源（图片、报告）
  - `__tests__`：基础测试样例
- wxapp/
  - `miniprogram/pages/*`：小程序页面（index、shop、order、checkout 等）
  - `miniprogram/utils/*`：数据、请求、收藏等工具
  - `README.md`：小程序说明（接口约定、资源目录）
- docs/
  - `API/`、`Database/`：接口与数据库设计文档
  - `diancan_data_tables.sql`：从 `diancan` 库导出的“有数据”的表的 DDL+DML
  - `rename_shops_to_canteenshops.sql`：表重命名脚本

## 依赖与版本
- 后端：
  - JDK 17（Eclipse Adoptium）
  - Spring Boot（版本见 `pom.xml`）
  - MySQL 8+（驱动：`com.mysql.cj.jdbc.Driver`）
- 前端：
  - Node.js 18+（建议）
  - Next.js（`web/package.json`）
  - 测试：Jest
- 小程序：
  - 微信开发者工具（基础库随工具）

## 常用命令
```powershell
# 后端（根目录）
mvn -f backend/pom.xml clean package
java -jar backend/target/*.jar

# 前端（web 目录）
cd web
npm install
npm run dev

# 重新导出数据库（根目录）
node tools/export-diancan.js
```

## 环境变量（可选）
- DB_HOST / DB_PORT / DB_USER / DB_PASS / DB_NAME：覆盖数据源
- OUT_FILE：导出 SQL 的输出路径

## 接口示例
- GET `/api/v1/canteens`
- GET `/api/v1/shops/{id}/comments`
- GET `/api/v1/merchant/dishes/{id}`

## 注意事项
- 数据库当前使用表名 `canteenshops` 存储商家信息；请确保所有 SQL 指向该表。
- 前端路径仍可能使用 `/shops` 作为对外路由名称，后端已兼容。必要时可统一改为 `/canteenshops`。
