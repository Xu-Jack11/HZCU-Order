# 项目程序清单 (Program Listing)

## 1. 后端程序 (backend)

### 核心 Java 路径 (`src/main/java/com/hzcu/order/`)
- **[controller/](backend/src/main/java/com/hzcu/order/controller)**: 接口入口（订单、支付、用户、菜品）。
- **[service/](backend/src/main/java/com/hzcu/order/service)**: 核心逻辑（余额计算、状态机触发）。
- **[entity/](backend/src/main/java/com/hzcu/order/entity)**: 数据库实体模型 (Order, User, Dish, Canteen)。
- **[repository/](backend/src/main/java/com/hzcu/order/repository)**: JPA 数据访问持久层。
- **[dto/](backend/src/main/java/com/hzcu/order/dto)**: 前后端交互对象映射包装。
- **[security/](backend/src/main/java/com/hzcu/order/security)**: JWT 安全鉴权与配置中心。

### 核心配置文件
- **[application.yml](backend/src/main/resources/application.yml)**: 数据库连接、Redis 及项目全局配置。

---

## 2. 商家端 Web (web)

### 页面结构 (`app/`)
- **[admin/](web/app/admin)**: 平台管理员后台页面（食堂、财务、用户管理）。
- **[dashboard/](web/app/dashboard)**: 商家实时概览（今日营收单量、订单实时监控）。
- **[login/](web/app/login)**: 商家登录门户。

### 资源与工具
- **[components/](web/components)**: 核心业务组件（订单卡片 `OrderCard`、侧边栏 `Sidebar`）。
- **[lib/api.ts](web/lib/api.ts)**: 基于 axios 封装的统一 API 吊起工具类。

---

## 3. 微信小程序 (wxapp)

### 核心页面 (`miniprogram/pages/`)
- **[index/](wxapp/miniprogram/pages/index)**: 食堂与菜品列表首页。
- **[mine/](wxapp/miniprogram/pages/mine)**: 个人中心、余额与充值页面。
- **[order/](wxapp/miniprogram/pages/order)**: 订单列表与下单确认流程。

### 工具脚本 (`miniprogram/utils/`)
- **[request.ts](wxapp/miniprogram/utils/request.ts)**: 小程序请求基类。
- **[cart.ts](wxapp/miniprogram/utils/cart.ts)**: 客户端购物车持久化逻辑。
- **[api.ts](wxapp/miniprogram/utils/api.ts)**: 小程序业务 API 接口映射文件。
