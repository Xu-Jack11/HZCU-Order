# HZCU-Order 项目模块结构说明

> 版本：1.0 | 更新日期：2024年

## 一、项目概述

HZCU-Order（城院点餐）是一个校园食堂点餐系统，采用前后端分离架构，包含三个主要端：
- **后端服务**（backend）：基于 Spring Boot 的 RESTful API 服务
- **Web 管理端**（web）：基于 Next.js 的商家与管理员 Web 应用
- **微信小程序端**（wxapp）：面向师生用户的点餐小程序

---

## 八、运行与部署

### 8.1 后端运行

```bash
# 进入后端目录
cd backend

# Maven 构建
mvn clean package

# 运行
java -jar target/*.jar
```

### 8.2 Web 前端运行

```bash
# 进入 web 目录
cd web

# 安装依赖
npm install

# 开发模式运行
npm run dev
```

### 8.3 小程序运行

1. 使用微信开发者工具打开 `wxapp` 目录
2. 配置 `project.config.json` 中的 AppID
3. 编译并预览
