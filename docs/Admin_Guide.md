# HZCU-Order 系统管理员操作指南

本指南旨在帮助系统管理员快速上手 HZCU-Order 平台的管理后台（Backend Admin）。

## 1. 登录系统

- **访问地址**: `/admin/login`
- **默认账号**: `admin` (示例)
- **默认密码**: `password` (示例)

管理员需通过专用入口登录，与商家端 (`/login`) 相互独立。

## 2. 平台概览 (Dashboard)

登录后默认进入平台概览页 `/admin/dashboard`，您可以在此查看：
- **核心数据**: 注册用户总数、入驻食堂数、今日交易额 (GMV)。
- **系统状态**: 检查是否存在系统告警或服务异常。

## 3. 功能模块

### 3.1 食堂管理 (Canteen Management)
- **路径**: `/admin/dashboard/canteens`
- **功能**:
    - 查看所有食堂的营业状态、评分、负责人。
    - 点击 **"编辑"** 按钮修改负责人姓名和联系电话。
    - 点击 **"停业/启用"** 按钮快速控制食堂状态。
    - 点击 **"商家"** 按钮，弹出商家管理窗口，可查看、移除或添加该食堂下的入驻商家账号。
    - 新增食堂或删除违规食堂。

### 3.2 用户管理 (User Management)
- **路径**: `/admin/dashboard/users`
- **功能**:
    - 通过姓名、学号或手机号搜索用户。
    - 点击 **"编辑"** 按钮修改用户手机号。
    - 点击 **"封禁"** 按钮禁止违规用户登录或下单。
    - 点击 **"解封"** 恢复正常权限。

### 3.3 财务报表 (Finance)
- **路径**: `/admin/dashboard/finance`
- **功能**:
    - 查看平台月度总营收和净利润（抽成）。
    - 查阅近期详细的交易流水与结算记录。
    - 导出财务报表。

### 3.4 系统设置 (Settings)
- **路径**: `/admin/dashboard/settings`
- **功能**:
    - **轮播图配置**: 管理小程序首页的轮播广告。
    - **公告管理**: 发布由于系统维护或放假通知的全局公告。
    - (待开发) 优惠券管理与角色权限配置。
