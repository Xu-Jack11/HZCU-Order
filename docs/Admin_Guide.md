# HZCU-Order 系统管理员操作指南

本指南旨在帮助系统管理员快速上手 HZCU-Order 平台的管理后台（Backend Admin），包括登录、食堂管理、用户管理与平台监控。

## 1. 登录系统

- **访问地址**: `/admin/login`
- **默认账号**: `admin`
- **默认密码**: `password` (开发环境示例)

管理员需通过专用入口登录，与商家端 (`/login`) 相互独立。

## 2. 平台概览 (Dashboard)

登录后默认进入平台概览页，您可以在此查看：
- **核心指标**: 注册用户总数、入驻食堂数、今日交易额 (GMV)。
- **系统状态**: 检查是否存在系统告警或服务异常。
- **趋势图表**: (待集成) 最近 7 天的平台活跃度与交易趋势。

## 3. 食堂管理 (Canteen Management)

进入 **"食堂管理"** 菜单，您可以：

- **查看列表**: 浏览所有入驻食堂及其负责人、联系方式、当前评分。
- **启停业**: 点击 "停业/启用" 按钮，快速切换食堂的营业状态。
    - *停业*: 食堂在 C 端将显示为 "休息中"，不可接单。
    - *启用*: 恢复正常营业。
- **新增食堂**: 点击 "新增食堂" 按钮，录入新食堂信息（名称、位置、管理员账号）。
- **删除食堂**: 移除食堂及其关联数据（请谨慎操作）。
- **编辑信息**: (功能开发中)修改食堂基本资料。

## 4. 用户管理 (User Management)

进入 **"用户管理"** 菜单，您可以：

- **搜索用户**: 通过姓名、学号或手机号快速查找 C 端用户。
- **查看详情**: 查阅用户注册时间、状态等信息。
- **封禁/解封**: 针对违规用户（如恶意刷单、发布不当言论），可进行封禁处理。
    - *封禁*: 用户将无法登录小程序或下单。
    - *解封*: 恢复用户权限。

## 5. 财务与设置 (待开发)

- **财务报表**: 查看平台抽成、结算记录。
- **系统设置**: 配置平台全局参数（如轮播图、公告）。
