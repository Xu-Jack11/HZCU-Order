# 个人项目总结 - 杨坤洁

## 1. 清晰定位：项目概述与个人角色
**项目背景**：
城院点餐项目是针对浙大城市学院校园环境开发的订餐管理系统，旨在通过信息化手段优化食堂订餐流程，提升师生就餐体验。

**个人角色**：
在本项目中，我担任**项目管理与核心开发设计**角色。主要负责项目进度的整体规划、用户端核心逻辑设计以及项目交付物（PPT、会议纪要）的整合与维护，确保项目按计划稳步推进。

---

## 2. 量化成果：具体工作与核心产出
在项目执行过程中，我主导并完成了以下关键任务：
- **项目规划与管理**：独立编写了《项目开发计划》，明确了里程碑节点；完成了 70% 的《会议纪要》，确保了团队沟通的高效透明。
- **系统设计**：
    - 参与编写《可行性分析报告》，为项目立项提供数据支持。
    - 完成了《总体设计文件》，定义了系统的整体技术架构。
    - 绘制了 **HIPO 图**（分层输入-处理-输出图），清晰展现了系统功能模块及其数据流向。
- **逻辑实现**：完成了**用户端伪代码**的编写，为前端交互逻辑与后端接口对接提供了核心算法参考。
- **演示与维护**：负责《实现和测试 PPT》及《维护 PPT》的核心部分编写，成功展示了项目的阶段性成果与后期保障方案。

- **组织协调能力**：作为开发计划的制定者，我学会了如何在有限的时间和人力资源下，平衡各模块的优先级。

## 6. 坦诚复盘：问题反思与改进方案
**存在问题**：
- **进度预估偏差**：在项目初期，对部分技术难点的攻克时间预估不足，导致开发计划在执行中进行了微调。
- **文档同步延迟**：会议纪要的整理有时未能做到即时发布，影响了部分信息的传递效率。

**改进方案**：
- **引入缓冲时间**：在未来的计划制定中，将为关键路径设置 10%-15% 的风险缓冲期。
- **模板化作业**：建立更高效的会议纪要模板，确保在会议结束后 2 小时内完成初稿并分发。

## 7. 展望未来：经验总结与成长规划
**经验总结**：
这次项目经历让我明白，一个成功的项目不仅需要扎实的代码，更需要科学的规划和严密的文档支撑。我从单纯的执行者成长为具备全局观的规划者。

**成长规划**：
- **进阶项目管理**：计划学习 PMP 相关知识，进一步提升项目风险控制和资源调度能力。
- **技术深度探索**：在掌握总体设计的基础上，深入研究分布式系统设计，提升应对大规模并发场景的能力。
- **持续贡献价值**：在后续工作中，我将继续发挥“管理+技术”的双重优势，推动团队交付更高质量的产品。
